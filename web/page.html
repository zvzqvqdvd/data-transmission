使用帮助

下载或启动时提示「不安全 / Windows 已保护你的电脑」？

程序没买数字签名证书（一年上千元），Windows 和 Chrome 认不出发布者，会按「未知发布者」拦一次，不是病毒。过法：Chrome 下载栏点「…」→「保留」；Windows 弹「已保护你的电脑」点「更多信息」→「仍要运行」。只从本页面或 GitHub 仓库下载，别用别处来的同名文件。

房间码是对的，却说找不到房间？

房主销毁过房间、或关掉程序重新开过，旧码就作废了；也可能是房主那边的程序或页面已经关掉。找房主重新要房间码，或者直接扫二维码/点邀请链接。

一直卡在「正在连接对方设备」？

先让两台设备连同一个 WiFi，在浏览器里打开房主给的局域网地址，走局域网通道最稳。跨网络时如果双方都在公司网、对称 NAT，直连会失败，可以点右上角的网络图标加一台 TURN 服务器中转；另外微信/QQ 内置浏览器不支持点对点，请用系统浏览器打开。

跨网络时如果双方都在公司网、对称 NAT，直连会失败，可以点右上角的网络图标加一台 TURN 服务器中转；另外微信/QQ 内置浏览器不支持点对点，请用系统浏览器打开。

桌面共享点不动 / 对方看不到？

共享桌面要求页面在 https 或 localhost 下打开，用 http://192.168.x.x 访问时浏览器会禁用采集，这是安全限制。手机浏览器只能看、不能发起共享。

点「复制」没反应？

非 HTTPS 页面不能调用系统剪贴板。本程序会自动退回到老办法复制；如果还是失败，长按或手动选中地址复制即可。

收到的文件存在哪了？

房主那台设备上：数据\房间\<房间码>\接收文件\。其他设备不会自动下载聊天里的文件，点文件卡片右边的下载按钮，就会从房主那边传过来，存在系统的下载目录里。

保存在房主的浏览器里（IndexedDB），房间销毁即清除。其他设备点文件卡片右边的下载按钮，就会从房主那边点对点传过来，存在系统的下载目录里。

大文件能传多大？

上传到本机最大 4 GiB。外网设备下载文件走点对点直连，速度取决于双方网络；文件始终保存在房主设备上，其他设备按需下载。

纯网页房间的容量按浏览器可用空间自动定：总量取可用空间的 80%，单文件上限是总量的 10%。房间侧栏的存储卡会显示本房间的实际数字。如果浏览器报不出可用空间（无痕模式或版本过旧），本房间直接禁止上传文件，不猜一个可能存不下的数字。传输文件请使用任意最新版浏览器，并且不要开启无痕（隐私）访问。文件走点对点直连，超大文件请改用局域网模式。

房间什么时候销毁

房间是临时的，出现以下任一情况就自动销毁：
· 关闭房主页面（刷新不算，页面回来就继续用）
· 房主离线（60 秒宽限，弱网抖动不算）
· 连续 60 分钟没有通信（发消息、传文件、新设备加入都算）
· 房主点「销毁房间」（立即生效）
销毁时房间码作废；聊天记录一律不落盘，局域网房间的接收文件随房间一起删除，不做保留。
